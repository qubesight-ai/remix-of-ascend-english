# Remix of Ascend English

# 🎯 Propósito Integral de la App de Inglés Autodidacta

**Propósito Central**: Crear un **sistema autodidacta completo e inteligente** que guíe al estudiante desde el nivel **A1 hasta C1** del MCER, funcionando como un **tutor personal 24/7** que combina estructura curricular, práctica conversacional con IA, autoevaluación y seguimiento del progreso.

---

## 📊 **1. Núcleo del Sistema: Progresión por Niveles MCER**

La app estructurará **todo el contenido** según los objetivos de cada salto de nivel:

| **Nivel** | **Duración Objetivo** | **Foco Principal** | **Característica App** |
|-----------|----------------------|-------------------|----------------------|
| **A1 → A2** | 12 semanas | Comunicación básica en situaciones cotidianas | Práctica muy guiada, vocabulario visual |
| **A2 → B1** | 16 semanas | Independencia en uso del idioma | Introducción a conversaciones extendidas |
| **B1 → B2** | 20-24 semanas | Comunicación fluida y profesional | Análisis de argumentos, registro formal/informal |
| **B2 → C1** | 6-12 meses | Precisión nativa y competencia académica | Crítica, inferencia, dominio de registro |

**Mecánica**: El estudiante **no elige su nivel**; la app lo evalúa continuamente mediante:
- Test diagnóstico inicial
- Análisis de rendimiento en ejercicios
- Evaluación de conversaciones con IA
- Autoevaluaciones periódicas

## 🤖 **3. Sistema Conversacional con IA (Tutor Virtual)**

### **Funcionalidades principales**:
```
SISTEMA DE PRÁCTICA CONVERSACIONAL:
├── **Avatares interactivos** con diferentes roles:
│   ├── Turista perdido (A1)
│   ├── Amigo en café (A2)
│   ├── Colega de trabajo (B1)
│   ├── Debate académico (B2)
│   └── Negociación profesional (C1)
├── **Corrección en tiempo real**:
│   ├→ Error gramatical: "Creo que dijiste 'I go yesterday'. La forma correcta es 'I went yesterday'"
│   ├→ Error de vocabulario: "'Big rain' se entiende, pero es más natural decir 'heavy rain'"
│   └→ Error de pronunciación (si hay voz): "La palabra 'thought' suena /θɔːt/"
├── **Modo "Enséñame a hacerlo bien"**:
│   └→ Tras corregir, la IA pregunta: "¿Quieres practicar esta estructura 3 veces?"
├── **Seguimiento de progreso conversacional**:
│   ├→ Fluidez: palabras por minuto
│   ├→ Precisión: % de errores gramaticales
│   ├→ Riqueza léxica: palabras únicas usadas
│   └→ Estrategias comunicativas: paráfrasis, petición de clarificación
└── **Recordatorios contextuales**:
    └→ "Hace 3 días practicaste el presente perfecto. ¿Quieres usarlo en esta conversación?"
```

## 🔄 **4. Metodología Autodidacta: "Aprender a Aprenderse"**

### **Sistema de autogestión del aprendizaje**:
```
CICLO DE AUTOGESTIÓN:
1. **Autoevaluación inicial** → "¿Qué sabes ya?" (test adaptativo)
2. **Plan personalizado** → "Esto es lo que necesitas aprender" (ruta visual)
3. **Práctica guiada** → "Haz esto, luego esto" (micro-lecciones)
4. **Autocorrección** → "¿Dónde te equivocaste?" (análisis de errores)
5. **Reflexión** → "¿Qué has aprendido?" (diario de aprendizaje)
6. **Nueva meta** → "¿Qué sigue?" (replanificación automática)
```

### **Herramientas de autogestión**:
- **Diario de aprendizaje integrado**: "Hoy aprendí que..." / "Aún me cuesta..."
- **Preguntas guía automáticas**: "¿Podrías explicar esta regla con tus propias palabras?"
- **Sistema de autopreguntas**: La app sugiere preguntas que el estudiante debe responderse
- **Mapa visual de progreso**: "Has dominado 45% de A2, te faltan estos 3 temas"

## 🎨 **6. Experiencia de Usuario y Diseño**

### **Principios de diseño**:
1. **Progresión invisible**: El estudiante nunca ve "lección 35 de 200", solo "hoy practicaremos esto"
2. **Feedback inmediato**: Cada acción tiene respuesta visual/auditiva
3. **Adaptabilidad constante**: La dificultad se ajusta tras cada ejercicio
4. **Multimodalidad**: Texto, audio, imágenes, video según el tema
5. **Contexto real**: Todas las prácticas simulan situaciones auténticas

### **Flujo de usuario típico**:
```
DÍA DE ESTUDIO:
1. Inicio de sesión → Dashboard muestra progreso
2. Calentamiento → 5-min conversación con IA sobre ayer
3. Foco del día → "Hoy: Present Perfect vs Past Simple"
4. Explicación breve → 2-min video/texto interactivo
5. Práctica controlada → Ejercicios de elección múltiple
6. Práctica libre → Conversación IA que requiere usar la estructura
7. Autoevaluación → "Del 1 al 5, ¿cómo te sentiste?"
8. Planificación → "Mañana practicaremos esto..."
```

## 🔧 **7. Requerimientos Técnicos para Replicar**

### **Stack tecnológico sugerido**:
- **Frontend**: React/Next.js con interfaz tipo dashboard
- **Backend**: Node.js/Python para lógica de negocio
- **IA conversacional**: 
  - OpenAI GPT-4/Claude para generación
  - Whisper para reconocimiento de voz
  - Modelo fino ajustado para corrección gramatical
- **Base de datos**: PostgreSQL para progreso + Redis para sesiones
- **Contenido**: CMS para gestionar 5.000+ ejercicios

### **Algoritmos clave**:
1. **Sistema de espaciado repetitivo**: Para vocabulario/gramática
2. **Motor de dificultad adaptativa**: Ajusta ejercicios en tiempo real
3. **Analizador de errores**: Patrones comunes por lengua nativa
4. **Generador de rutas**: Crea plan personalizado basado en objetivos
